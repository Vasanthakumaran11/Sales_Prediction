## 🔧 Customization Options

### Easy to Customize

```python
# Change training period
DAYS_RANGE = 120  # More historical data

# Add more stores
NUM_STORES = 10

# Customize products
PRODUCTS = { 'YourProduct': {...} }

# Adjust retraining threshold
MIN_DATA_POINTS_FOR_RETRAIN = 7  # Weekly instead of biweekly

# Change inventory service level
Z_SCORE = 2.33  # 99% instead of 95%
```

### All in Configuration File
- `src/utils/config.py` - Single source of truth
